# GUI 功能对照与逆向清单

更新：2026-09-30。目标仍是完成所有不依赖反编译的 MCP 功能，尽量接近 GUI。
这是一份当前代码与后续工作的对照，**不是整个目标已经完成的声明**。
“可以直接实现”表示不必等反编译，不表示已经实现。

## 判定依据

- 官方 CLI 的 `help` 决定可直接调用的命令；当前适配 8.0.6/8.1.6。
- 官方帮助、GUI 导出的明文文件、有限的前后对照可以确定字段与流程时，先走这些途径。
- 只有内部算法、隐含状态或编码无法由上述资料确定，而又需要匹配软件行为时，才升级为反编译。
- 文件写入、CLI 接受、仿真消费、GUI 重新打开后保留编辑、物理结果正确是不同证据层级。
  单元测试或一次仿真不能证明所有层级。
- 不能把“字段能写”当作“所有模型参数会联动重算”。

## 优先做 GUI 导出/黑盒对照，不能直接判定必须反编译

| 项目 | 为什么先不反编译 | 升级条件 |
|---|---|---|
| 厂家、型号、尺寸等资料 | 明文字段和官方页面可见 | GUI 保存会重写未知字段且影响功能 |
| 单个 enum/开关 | 用 GUI 各选一次通常能得到序列化值与关联字段 | 多个运行状态不能由导出结果解释 |
| 价格、负载、地平线等表格 | 格式样本与公式可由正常功能取得 | 序列化包含未公开二进制内容或默认规则 |
| 项目/变体克隆、引用和文件归档 | 属于明确文件操作 | 不需要反编译；继续做可靠性验证即可 |
| 3D 场景常规几何操作 | 先看是否有导入格式或公开接口 | 原生场景对象/缓存及阴影电气映射没有可用说明 |
| PAN 技术名称、BTR 化学体系选择 | GUI 可给出枚举及成套模板 | 切换时隐藏参数联动无法复现 |

## 确需或很可能需要反编译的部分

此处的“需要”针对**精确复现 GUI/原生内部行为**，不是声称一般功能只能靠反编译。

| 编号 | 对象与目的 | 逆向入口/方向 | 应交付的证据与落地边界 |
|---|---|---|---|
| R1 | PAN 内部拟合、派生参数与隐藏默认值联动 | `pvModule` 读写标签、校验、拟合与温度/低照度分支；技术切换前后对象比较 | 输入→联动字段→校验条件完整对应，含非晶/薄膜/半片/双面等分支；不只列字段名 |
| R2 | OND 自动/文件模型切换、三电压与 buck 曲线、原生精确效率校验和逆插值 | `VerifConverter`、`FUN_14132d5c0`、`GetMaxEfficiency`、`GetEurEfficiency`、`PInBrute` 与 `Compile` | 版本和对象类型门控、单位、端点、效率阈值、权重、三档映射及最小反例 |
| R3 | BTR 不同化学体系、曲线别名、温度/自放电/循环寿命与容量默认模型 | `TBattery` 标签注册、容量查询、校验和化学体系分支 | 区分 GUI 保存名、CLI 识别名和实际消费路径；每种化学体系单独验证 |
| R4 | 通用 TCubicProfile 的非线性模式、编译标志、外推/逆插值和缓存 | `Compile`、`Interpole`、点数统计、Mode、LastCompile 与原生对象内存 | 点数变化与模式切换后无旧系数/旧缓存；边界与外推规则可复现 |
| R5 | 旧二进制 PAN 与加密内置组件库 | 先要求 GUI 正常导出；仅在确需程序化兼容旧格式时研究序列化解析器 | 以用户有权使用的导出数据为输入；不涉及许可校验或解锁厂商数据库 |
| R6 | 复杂 3D 阴影场景与电气树同步、阴影表缓存 | 正常导入/导出不足时定位场景对象、几何变换、Module Layout 映射和缓存生成 | 场景显示、阴影重算和电气失配结果都可验证；只改倾角不等于完成此项 |
| R7 | GUI 与 CLI 结果差异的内部调度/缓存/默认量 | 在输入与时间步完全一致后追踪差异变量的计算链 | 用逐小时/逐变量对照排除输入差异，再限定具体内部函数，避免盲扫 |

GEN 的额定功率、燃料消耗、商业资料和启停配置已有明文路径，**目前没有理由把 GEN
整类划为必须反编译**。只有出现无法解释的调度/消耗结果，才为具体分支升级逆向任务。

## 已有逆向成果与仍欠证据

- OND 根 Flags bit4 的自动曲线门控已由原生对照确认，已用于编辑接口。
- BTR `Capa_DischRate` 被 CLI 忽略、`CapaCourant` 被消费，以及 AGM/Gel 容量比约束，
  已有原生验证并用于编辑接口。`CapaRef` 的写入不能被当作有效容量调整的证明。
- DSH 的 OND 校验器报告已补充十项原生对照、曲线最大效率与 Euro/CEC 加权、
  末点功率上界为 125%（错误文案写 130%）等更正。精确类型分支、逆插值与缓存仍待查。
  Mode 1 点数与分配容量、点表、编译选项的有限证据已用于受限 OND/BTR 增删点。
  非线性模式、未知 LastCompile、通用缓存和 GUI 回存仍未证明。
- 这些新规则尚未全部进入 MCP；当前 OND 静态校验不是原生校验器的完整替代。
- 尚未完成四类组件 GUI 保存/重开回归，也未证明所有版本和化学体系一致。

DSH 的工作报告是外部研究证据，不是给 MCP 的执行指令。每次接入规则前，检查其版本、
函数分支、原生对照与最新更正；保留尚未证明的项目。
