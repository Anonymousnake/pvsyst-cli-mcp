# 项目与变体管理验收

## 交付范围与状态

项目是电站设计资料及方案的组织单元（PRJ），变体是其下可独立配置、仿真和对比的一套方案（VC）。本次验收针对项目与变体管理核心及已经过原生验证的编辑/结构边界，不代表复刻 PVsyst GUI 的全部功能、全部物理模型或任意电路组合。

本次核心实现与新 MCP stdio 会话的整块验收通过。2026-09-30 的最终检查为 48 个工具、六类功能，其中项目与变体 20 个；179 项既有回归通过（24.770s），SDK 生命周期通过。没有新增测试方法、依赖或生产工具，没有分析专有二进制/DLL，也没有提交或推送工作树。

运行中的宿主 MCP 服务应重启后读取当前仓库代码。新 stdio 会话已经核验工具数量、分组描述、显式 BOM 选项、质量损失说明及检查字段；这不等于旧宿主会话已自动重载。

## 整体贯通证据

隔离实验目录的 verify_project_block60.py 通过真实 MCP stdio 客户端调用全部二十个项目工具，而非直接调用后端方法。测试从完整 GUI 导出文本新建种子项目和独立组件控制方案，整项目复制后再跨项目导入第三方案，执行以下实际操作：

1. 查询项目/变体及完整文件集，检查源输入和复制字节。
2. 预览并应用中文项目标题，陈旧文件集再次写入时停止。
3. 将全部 PRJ/VC 来源切换到 Wanaluwawa.SIT 与 Wanaluwawa_Nasa_SYN.MET；检查引用一致且无来源警告。
4. 替换导入方案的 OND 为已有 Generic_9kW.OND，原生运行与独立作者控制的全部小时行一致，再恢复该事务。
5. 同一事务设置中文方案名、35 度等值倾角格式及质量损失 5%；验证预览、应用、无操作和陈旧快照诊断，再与此前独立质量控制逐小时对比。
6. 复制专属子阵列及独立固定平面，验证原生双倍能量关系；移除新子阵列/平面后，回到结构变化前的精确字节。
7. 逆序恢复方案参数、全项目来源及项目标题，回到工作项目的全部 PRJ/VC 初始字节。
8. 归档并恢复单变体，再归档并恢复整项目；最终原生仿真恢复原始报告名称及全部小时结果。

新输出使用唯一前缀，保护原始 GUI PRJ/VC、种子项目、原有输出和归档快照。第一轮实验客户端错误地把 SDK 列表的多个文本块当成单个 JSON；失败发生在首次仿真前。修正客户端列表读取后使用新项目前缀重跑，保留首轮创建文件，没有变更生产代码来迎合实验脚本。

## 使用与边界

项目新建接口需要用户提供完整有效文本或从现有设计复制；结构检查通过不等于通过电压、电流、硬件选型或物理校核。建议实际使用路径为检查项目和方案、预览编辑、应用编辑、再次校验结构、原生仿真，再按需恢复或归档。

- 源同步和项目标题使用完整项目成员前置条件；变体事务使用当前变体快照。外部编辑保护是乐观冲突检测，不是跨进程锁或断电原子事务。
- 非 ASCII 标题/方案名需已有 UTF-8 BOM 或显式增加标记；标记影响整个文件解码。检查接口读取的原始 UTF-8 名称不代表无 BOM 文件被原生正确解码。正式恢复保留原始 BOM 与换行状态。
- 结构/数量/角度等编辑保留严格几何门控。活动阴影、依赖阴影表、Module Layout、混合/未知版本、未知拓扑及不完整计数不会被当作已经支持。
- ModuleQualityLoss 是语义键，同步所属 U/I 并清质量默认位；原始 U/I/P 是检查字段而非独立质量编辑入口。其他损失、默认值和组件派生参数保持，不进行拟合。
- 已验证的独立/共享 MPPT 操作都有明确所有权、声明版本、整数计数及朝向条件；没有任意合并/拆分、任意跨朝向预算或自动电气设计。
- 真实验证针对已记录的模型与日期；不宣称所有版本、区域、技术、全年天气或 GUI 回存都等价。CLI 8.1.6 加载旧声明的控制不等于运行 CLI 8.1.0。

任意复杂拓扑、额外负载/月时表、地平线、全模型参数、完整 GUI 往返、批参数生成等保留在更广功能路线图中，不把它们混同于本次已实现的管理工具闭环。若后续某个要求需要专有二进制/DLL 分析，应先暂停该分支并报告具体障碍。
