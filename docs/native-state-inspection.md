# 原生存储状态读取：R49

本批选择性复用参考开发线51148b9的已记录字段映射，扩展既有`pvsyst_get_variant_parameters`，不新增工具、不移植DC比例反算、原生VC构造或大量内部测试。读取到字段、可编辑字段和原生消费是不同状态；本批只提升可观察性，写入范围保持原有门禁。

## 返回内容

| 字段 | 返回与边界 |
|---|---|
| `transformers` | 每个原生TransformerNode的七项存储字段、层级深度与嵌套关系；`count`是序列化层数，不是变压器台数。不换算电压、参考功率或铁铜损 |
| `system_unavailability` | pvSystem自身SystemUnavail的模式、目标比例/段数/时长/种子和存储时段；与WeakGrid电网可用性分开，不从种子生成或重新安排时段 |
| `peak_shaving` | 已记录PeakShaving的AfterSunset或小时窗、功率/SOC/效率原始字段；使用既有owner解析跳过嵌套对象，不把子对象同名字段当主字段。不计算调度或端点包含关系 |
| `shading_scene` | owner标志、ListeObjets内物体计数和类型、owner存储标量；原生分组位于该列表之后，不计入物体。后续新增[保存PV表关联](native-scene-bindings.md)与原生坐标声明读取；不解码一般网格/遮挡，不把原生坐标当房屋坐标或源几何认证 |
| `ageing.template` | 已验证模板的11个原生模式、保留/分配/RMS和保修列表字段；保修数组保持存储文本，旧年数/均值编辑范围不变 |
| `subarrays[].iam` | 组件缓存、ASHRAE、FresnelSmooth、UserProfile的有效/存储模型分开报告；后两类可读存储点值，不计算曲线 |
| `p50_p90` | 对已记录四种root flags读取实际存在的14字段块；没有块仍报none，不构造概率页或推算概率 |

未知、重复或不完整的局部记录显式返回issue，缺席与已配置分开。PV不可用列表最多1000段，超限停止返回列表，避免把截断误报成完整安排。新字段不代表所有任意原生版本或嵌套形态都已支持。

## 写入边界

P50写入仍要求原生结果模板`$01800001`；读取扩展到其它已记录root状态不放宽写入。IAM的FresnelSmooth与UserProfile在此入口均保持只读，避免共享读取器变宽后隐式扩大写入，更避免删除用户点表。组件默认与ASHRAE原有编辑不因读取能力而升级为新模型生成器。其它老化启停/RMS、PV不可用比例、朝向和线损写入仍待各自批次。

## 验证

新stdio MCP进程28次公开调用，全部在系统临时工作区复制的真实原生样本上进行；CLI路径为非可执行占位文件，本批没有运行PVsyst或改GUI/INI。验证了：MV一层/HV两层与两台配置仍一层的区别；42个PV停运时段及声明；四种IAM读取、85度0.40195与用户50度0.97000点值、两类只读表的双向编辑停止；P50三类有块状态可读但仅结果模板可写；无块状态；两类削峰和嵌套子对象owner隔离；11个老化字段；住宅20构件加2PV以及无场景状态。

首轮在住宅样本失败：参考实现对pvShading全体PVObject计数，把ListeObjets之后的原生分组算成第23个物体。保留`native-migration-r49/public-state-contract.json`，仅修正读取范围到实际ListeObjets边界后，以原22个物体目标重新执行，`public-state-contract-fixed.json`记录28次通过、输入字节保留。没有降低目标或删去失败输入。

真实缺陷提炼为一条长期公共协议契约`tests/contracts/test_native_parameters.py`：使用小型合成读取夹具，通过实际MCP工具验证缺席、物体与分组分离、计数不符、重复owner及输入保留；不导入实现模块、不依赖本机商业样本、不调用原生可执行程序、不计算/校验哈希。临时真实样本验证覆盖其余字段，不固化每个内部函数或复制参考线测试套件。

本批不重跑已有年度能量记录：返回的是存储数据，不是新物理计算或写入消费。未运行全量发现、旧smoke或哈希类探针；生产并发保护保持，公共更新反例仅照常使用原API回传的并发标记。定向编译及该唯一长期公共契约通过。性能未做独立基准，读取仍受既有文件大小上限约束。
