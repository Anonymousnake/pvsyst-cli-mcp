# 原生季节倾角写入

`pvsyst_update_variant_parameters` 的独立 `seasonal_updates` 事务现在可把已验证的固定平面切换为原生季节平面，或更新已有季节平面。它只保存PVsyst原生参数，按月选角、辐照、温度和能量都由软件计算。

```json
{
  "project": "SEASONAL_PLANE.PRJ",
  "variant": "VCH",
  "expected_sha256": "<当前检查返回值>",
  "seasonal_updates": {
    "summer_tilt": 10,
    "winter_tilt": 30,
    "winter_months": [1, 2, 3, 10, 11, 12],
    "orientation_name": "SEASONAL_S10_W30"
  }
}
```

两角度均须明确给出，非负且不超过90°、0.1°步长；`winter_months` 为1至11个不重复的原生JSON整数，范围1..12，其余月份交由PVsyst按原生季节模式处理。月份顺序不影响保存的mask，不接受全年单一季节的未验证配置。没有自动优化角度、地理推断或工程默认值。

可选 `orientation_name` 只改拥有的平面Comment，不是根变体名；未给时保留旧名称，不自动生成标签。可与既有 `variant_name` 同事务使用。非ASCII平面名要求VC已有明确UTF-8 BOM，或通过既有根变体命名的显式BOM事务处理；不隐式改变整个文件的解码方式。

## 原生保存与门控

原生GUI参考显示需要成套保存 `FieldType=SeasonalTilt`、`FieldTilt=0.0`、`SummerTilt`、`WinterTilt`、`WinterMonths`。固定模式零值 `BaseSlope` 随切换删除，非零坡度阻断；已有季节模式若含BaseSlope也阻断未知缓存。`FieldAzim`、NoOrient、三个Uses*Aver、BTNoTrackers、电气分配、其他损失和天气保持原样。`FieldTilt=0` 不是有效夏冬角度。

本切片限定8.1.6原生PV-only Grid、单子阵/单平面且所有组串在方向1，要求完整可核对的电路计数、已验证主阵列标志、平面Flags为零且非平均、无活动几何/布局、无负荷/储能、自由地平线和普通系统Flags=$00。跟踪、Dome、平均平面、坡地、地平线、辅助/PF/限值等耦合状态在写入前停止，不清理或覆盖未知状态。其他参数另开事务。

复用既有预览、无操作、守卫、备份与恢复。该入口不是固定模式回切器；需恢复原平面时使用本次事务返回的备份及当前快照令牌。没有重算几何映射或自行生成阴影表。
