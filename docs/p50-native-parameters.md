# 原生 P50/P90 参数编辑

`pvsyst_get_variant_parameters.p50_p90` 检查已保存的原生参数；`pvsyst_update_variant_parameters(..., p50_p90_updates=...)` 在一个事务中编辑十四项参数，可附带 `variant_name`。只读写 `P50_P90=TP50_P90` 的既有标签，不实现概率分布、标准差合成或分位计算。概率结果和图表全部由 PVsyst 计算及生成。

## 输入契约

本阶段使用原生键，不做别名或单位换算，十四项全部必填：

```json
{
  "MeteoKind": "SpecYear",
  "P90Custom": 85,
  "PxxCustom": 97,
  "PxxReport": true,
  "PxxMainResults": true,
  "PlotKind": 1,
  "YearDevFromAver": 2.3,
  "MeteoAnnualVariab": 4.2,
  "PVModelVariab": 2.11,
  "InverterVariab": 0.62,
  "SoilingVariab": 1.23,
  "DegradVariab": 1.34,
  "CustomVariab": 0.45,
  "CustomVarLabel": "Declared test uncertainty"
}
```

以上为实验输入，不是该站点的不确定度评估或工程建议。具体年份/自测天气本身不是 P50 的代表；资料种类与年度偏差须有各自依据。`TMY` 在本地试验中仅用于分支验证，不把 Imported 单年文件变成真实多年气象。

- `MeteoKind` 仅支持 `SpecYear`、`TMY`；后者忽略年度偏差的实际作用，但保留显式输入的 `YearDevFromAver` 保存值，不替用户清零。
- 两个分位参数为严格整数，适配器要求 `51 <= P90Custom < PxxCustom <= 99`。字段名 P90Custom 不表示固定90：原生实际输出 P85/P97 已验证。
- `YearDevFromAver` 是百分比，支持域 [-100,100]；六个 Variab 字段均为百分比，支持域 [0,100]；均限0.001增量。这些是适配器域，不是 GUI 完整输入域或科学合理性保证。
- `PxxReport` 控制概率报告章节，`PxxMainResults` 控制主要结果中的分位指标；均为严格布尔。`PlotKind=1` 为本轮已证概率分布，累计图尚未接入。
- `CustomVarLabel` 限1–80字节可打印、无首尾空格的单行 ASCII。`T_TEST` 等名称按字符串处理，不误判为嵌套类型。

GUI 的变率/模型勾选框会恢复软件默认值，而不是启用/排除该项。默认框在十四字段中没有独立保存标志；此接口只保存明确数值，不承诺自动默认模式或自动气候估算。当前夹具的默认气象变率保存为2.812%、显示为2.8%，不外推其它站点或版本。

## 模板与事务边界

只接受既有 GUI 原生 P50 结果模板：8.1.6、根 Flags 数值 `$01800001`、一个根级平坦 P50 标签块及完整十四字段；同时要求普通 PV-only Grid、单固定平面/子阵、自由地平线、无几何及完整电路计数。现有预览、无操作、备份、恢复及来源冲突保护沿用原机制。

不新建/删除 P50 块，不设置或解释结果状态位，不修改结果缓存、物理输入、站点、气象或组件。PF/限电/辅助/温度/储能等耦合及同时修改其它物理参数保持阻断。新增、重复、缺失、非 owning、嵌套或未知字段均在写入前阻断；已注册但未在本轮 GUI 写出的 `ClimateChange` 也保持待审。

仅复制标签尚不足以构造完整的新 P50 报告：无结果的基线添加相同十四字段后，原生 CLI 能算出主结果分位，但默认报告没有概率专页；仅添加GUI前后差分中出现的根级bit24仍未显示该页。显式 `report_pages="p50p90"` 又在原生加载阶段报该页不可用。上述失败均保留，未据此伪造缓存或放宽入口。本阶段用原生结果模板复制后编辑；从无结果工程构造完整 P50 报告仍待定位。
